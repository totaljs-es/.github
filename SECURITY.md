# Security

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Write to **info@totaljs.es** with:

- what you found and where (the repository, the file or the service),
- how to reproduce it, and which version you used,
- what you think the impact is.

If the repository has *Report a vulnerability* under its Security tab, you can use that instead: it stays private.

We will answer as soon as we can, work on a fix, and credit you when it is published if you want us to.

A repository can have its own `SECURITY.md`; when it does, that one applies.

# Contributing

Thank you for helping. Contributions are welcome in Spanish or English.

- **A question or an idea:** open an issue and describe what you want to do before you write a lot of code.
- **A bug:** open an issue with the version, the steps to reproduce it, what you expected and what happened.
- **A change:** fork the repository, make a branch, keep the change small and focused, and open a pull request that says what it changes and why. Run the checks or tests of the repository if it has them.
- **Security problems:** do not open an issue; see [SECURITY.md](SECURITY.md).

By contributing you agree that your contribution is published under the license of the repository. Please follow the [code of conduct](CODE_OF_CONDUCT.md).

A repository can have its own `CONTRIBUTING.md`; when it does, that one applies.

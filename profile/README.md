# Spanish Total.js

Tools, distributions and learning material around [Total.js](https://www.totaljs.com), from [totaljs.es](https://totaljs.es). Spanish Total.js is a community project; it is not the official Total.js organization.

## Projects

| | |
|---|---|
| **[Developer Distros](https://github.com/totaljs-es/developer-distros)** | Linux for Total.js development on Ubuntu LTS and Arch, with the same desktop on both: live ISOs, a graphical installer and a signed package repository. |
| **[TotalFusion](https://github.com/totaljs-es/totalfusion)** | Call Python, Rust, Go and WebAssembly from Total.js and Node.js as plain `async` functions, with workers, streaming and MCP tools for agents. |
| **[Totem](https://github.com/totaljs-es/totem)** | A coding agent for Total.js projects: free and local models first, paid ones only when it matters. |
| **[Flowee](https://github.com/totaljs-es/flowee)** | Total.js Flow, education edition: visual programming for the classroom, in a Docker image. |
| **[TotalMail](https://github.com/totaljs-es/totalmail)** · [app](https://github.com/totaljs-es/totalmail-app) | A self-hosted webmail, and its app for Windows, Linux and Android. |
| **[Code app](https://github.com/totaljs-es/code-app)** | Total.js Code on the desktop for Windows and Linux. |
| **[Knowledge](https://github.com/totaljs-es/knowledge)** · [Conventions](https://github.com/totaljs-es/conventions) · [Guidelines](https://github.com/totaljs-es/guidelines) | Small complete Total.js 5 applications and the conventions they follow, open to people and to any model. |
| **[Benchmarks](https://github.com/totaljs-es/node-framework-benchmarks)** | Reproducible benchmarks of Total.js against Express, Fastify, NestJS, AdonisJS and plain Node.js. |
| **[Toto](https://github.com/totaljs-es/toto)** | The European red fox, mascot of Spanish Total.js. |
